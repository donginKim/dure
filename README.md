# 두레 (dure)

여러 AI 코딩 에이전트에게 일을 나눠 시키고, 그 에이전트들이 서로 연락하며 일하게 하는 macOS 데스크톱 앱입니다 (ADE, Agentic Development Environment).

프로젝트에 기획서를 주면 조율 에이전트가 분석해 계획안을 올리고, 사용자가 검토·승인하면 저장소마다 작업 폴더(git worktree)와 에이전트가 만들어져 TODO 를 따라 일합니다.

- 에이전트: Claude Code (`claude` 명령) 를 띄워 씁니다
- 만든 것: Electron, TypeScript, React, SQLite
- 상태: 버전 0.1.0. 개인이 쓰며 만드는 중입니다

## 무엇을 할 수 있나

**프로젝트와 워크스페이스**
- 프로젝트에 저장소를 여러 개 등록하고, 저장소마다 워크스페이스(브랜치와 작업 폴더, 에이전트 하나)를 만듭니다. 원본 폴더는 건드리지 않습니다.
- 워크스페이스마다 대화 화면, 터미널, 변경(diff) 보기, 내장 브라우저가 있습니다.
- 에이전트가 하는 일을 요약해 보여 주고, 워크스페이스 이름을 자동으로 붙입니다.

**조율 에이전트와 계획안**
- 프로젝트마다 조율 에이전트가 하나 있습니다. 기획서를 주면 정리, 만들 워크스페이스, TODO 를 계획안으로 올립니다.
- 계획안은 사용자가 검토 화면에서 고치고 승인해야 만들어집니다. 승인 전에는 아무것도 만들지 않습니다.
- 계획안에 새 저장소(빈 git 저장소)나 PC 에 이미 있는 저장소 폴더의 등록을 넣을 수 있습니다.
- 조율 에이전트는 코드를 직접 고치지 않습니다.

**TODO**
- 프로젝트와 워크스페이스마다 TODO 가 있고, 사용자와 에이전트가 같이 봅니다. 사용자가 화면에서 고치면 에이전트에게 전해집니다.

**에이전트끼리의 메시지**
- 같은 프로젝트의 워크스페이스끼리 메시지와 자료(API 형식, 결정, 결과)를 주고받습니다.
- 주고받은 것은 대화 패널에 남고, 사용자가 멈추거나 끼어들 수 있습니다. 왕복 횟수에 상한이 있습니다.

**커밋**
- 에이전트는 원본 저장소에 직접 커밋·push 하지 못합니다. 커밋 초안을 올리면 사용자가 보고 커밋합니다. push 는 사용자가 누를 때만 합니다.

**DB 조회 (읽기 전용)**
- PostgreSQL, MySQL 연결을 등록하면 에이전트가 조회할 수 있습니다. 쓰기는 막혀 있고, 연결마다 "물어보고 조회 / 바로 조회 / 끔" 을 고릅니다.

**확인할 것과 알림**
- 에이전트나 다른 사람이 나를 기다리는 것(계획안 승인, 권한 요청, DB·슬랙·브라우저 승인, 받은 메시지와 일, 연결 요청)을 왼쪽 위 "확인할 것" 한곳에 모읍니다. 읽기·열기 승인과 받은 메시지는 거기서 바로 결정합니다.
- 새로 생기면 macOS 알림을 띄우고 Dock 아이콘에 수를 표시합니다. 알림을 누르면 그 화면이 열립니다.

**메모장**
- 프로젝트와 상관없이 하나인 메모장입니다. 어느 화면에서든 왼쪽 아래 "메모" 나 `⌘⇧M` 으로 열어 적고, 낱말로 찾습니다. 적는 대로 저장됩니다.
- 설정에서 켜면 에이전트가 메모를 찾아 읽을 수 있고, "이거 메모해 줘" 라고 시킬 수 있습니다 (읽기와 쓰기를 따로 켭니다. 기본은 둘 다 꺼짐). 에이전트는 새 메모를 만들거나 끝에 덧붙이기만 하고, 적힌 글을 고치거나 지우지 못합니다.

**슬랙 읽기**
- 설정에 슬랙 사용자 토큰을 넣으면 에이전트가 채널, 스레드, 검색 결과를 읽을 수 있습니다. 올리거나 고치지는 못합니다. "물어보고 읽기 / 바로 읽기 / 끔" 을 고릅니다.

**내장 브라우저**
- 워크스페이스에서 개발 서버를 앱 안에서 봅니다. 에이전트가 페이지를 열고, 누르고, 입력하고, 화면을 찍을 수 있습니다. 처음 여는 주소는 사용자에게 묻습니다.

**다른 사람과 함께하기**
- 같은 네트워크에 있는 다른 사람의 두레와 서버 없이 직접 연결합니다. 두 사람이 화면의 6자리 숫자를 맞춰 보고 둘 다 눌러야 연결됩니다. 내용은 암호화돼 오갑니다.
- 프로젝트를 함께 열고, 워크스페이스마다 누구에게 보일지 정합니다 (기본은 비공개).
- 프로젝트를 연 사람(리더)이 계획안에서 일을 다른 사람에게 나눠 줄 수 있습니다. 받는 사람이 수락하면 그 사람의 PC 에 워크스페이스와 TODO 가 만들어지고, 리더에게 진행이 보입니다.
- 에이전트가 `@이름` 으로 함께하는 사람에게 직접 물을 수 있습니다. 입력창에 `@` 를 치면 사람 목록이 뜹니다.
- 다른 사람이 보낸 것은 기본적으로 사용자가 보고 넘겨줘야 내 에이전트에게 갑니다.

## 필요한 것

- macOS 12 이상
- `git`
- [Claude Code](https://claude.com/claude-code) (`claude` 명령) 와 로그인
- 개발하려면 Node.js (v26.12.0 에서 확인)

## 설치 (소스에서)

저장소를 받아 스크립트 하나를 실행하면, 이 Mac 에서 앱을 만들어 "응용 프로그램" 에 넣고 엽니다.

```sh
git clone https://github.com/donginKim/dure.git
cd dure
bash scripts/install.sh
```

- 처음에는 패키지를 받느라 몇 분 걸립니다. Node.js 22 이상과 `git` 이 있어야 합니다.
- 이 Mac 에서 직접 만든 앱이라 macOS 가 "확인되지 않은 개발자" 라고 막지 않습니다. 관리자 암호도 묻지 않습니다.
- **업데이트**: 두레가 저장소에 새 버전이 있는지 스스로 확인합니다 (6시간마다). 있으면 왼쪽 아래에 알림이 뜨고, "지금 업데이트" 를 누르면 받아서 다시 만든 뒤 두레를 다시 켭니다. 받은 저장소 폴더를 지우지 마세요. 손으로 하려면 `git pull` 한 뒤 `bash scripts/install.sh` 를 다시 실행합니다. 데이터(`~/Library/Application Support/dure`)는 그대로 남습니다.
- 설치한 뒤 Dure 를 끄고 켜는 것은 보통 앱과 같습니다 ("응용 프로그램" 의 Dure).
- "다른 사람과 연결" 을 처음 켜면 macOS 가 키체인 사용, 로컬 네트워크 찾기, 들어오는 연결 허용을 물을 수 있습니다. 모두 허용합니다.

설치 파일(`.dmg`)로 나눠 주는 방법은 [docs/packaging.md](docs/packaging.md) 에 있습니다.

## 개발

```sh
npx -y pnpm@12.18.0 install
npx -y pnpm@12.18.0 exec electron-vite dev     # 앱 띄우기
npx -y pnpm@12.18.0 test                       # 시험
npx -y pnpm@12.18.0 run typecheck              # 타입 검사
npx -y pnpm@12.18.0 run pack:mac               # macOS 앱으로 묶기 (Apple 실리콘, 서명 없음)
```

- 데이터는 `~/Library/Application Support/dure` 에, 작업 폴더는 `~/dure/worktrees` 에 생깁니다.
- 다른 데이터로 띄워 보려면 `DURE_DATA_DIR`, `DURE_WORKTREE_ROOT`, `DURE_REPO_ROOT` 를 줍니다.

## 구조

```
src/core       앱의 논리. Electron 을 쓰지 않아 시험에서 그대로 돌린다
  agents/      에이전트 띄우기, 지침, git 가로채기
  mcp/         에이전트가 두레와 주고받는 도구 (MCP 서버)
  peers/       다른 사람의 두레와의 연결 (암호화, HTTP, Bonjour)
  dbquery/     DB 조회 (읽기 전용 검사, 드라이버)
src/main       Electron 메인 프로세스 (창, IPC, 내장 브라우저)
src/preload    화면에 내주는 API (window.dure)
src/renderer   화면 (React)
src/shared     코어와 화면이 같이 쓰는 타입과 규칙
tests          시험 (vitest)
docs           설계 문서, 패키징 안내
```

에이전트는 두레가 띄운 MCP 서버(`dure`)의 도구로 두레와 정보를 주고받습니다: 프로젝트 보기, TODO, 메시지, 자료, 계획안, 커밋 초안, DB 조회, 브라우저.

## 알려진 한계

- macOS 만 됩니다.
- 에이전트는 Claude Code 만 확인했습니다. Codex 는 확인하지 못했습니다.
- 다른 사람과의 연결은 같은 네트워크 안에서만 됩니다. 서로 다른 PC 사이, 3명 이상은 아직 충분히 확인하지 못했습니다.
- 앱 안의 업데이트는 소스에서 설치한 앱에서만 됩니다. 설치 파일(`.dmg`)로 넣은 앱은 새 파일을 받아 덮어씁니다.
