# 두레 플러그인 본보기

두레의 설정 → 플러그인 → "폴더에서 설치" 로 이 폴더를 고르면 설치된다. 내용을 보고 승인한 뒤, 프로젝트의 현황 탭에서 켠다.

`plugin.json` 에 담을 수 있는 것:

| 항목 | 뜻 |
|---|---|
| `instructions` | 에이전트 지시문에 덧붙는 글. 글 그대로, 또는 이 폴더 안의 `.md`/`.txt` 파일 이름 (플러그인마다 4,000자까지) |
| `schedules` | 예약 본보기. 저절로 돌지 않고, 프로젝트의 예약에서 골라 추가한다 |
| `memory` | 프로젝트에서 처음 켤 때 그 프로젝트의 기억에 넣는 한 줄들 |
| `mcpServers` | 에이전트에게 붙일 MCP 서버. `{ "이름": { "url": "https://…" } }` 또는 `{ "이름": { "command": "npx", "args": ["-y", "…"], "env": { } } }` |

두레 안에서 플러그인의 코드를 돌리지 않는다. 코드가 필요하면 MCP 서버로 만든다.
